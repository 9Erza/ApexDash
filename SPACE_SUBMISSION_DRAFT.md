# Space / Marketplace Submission Draft

## Plugin name

ApexDash

## Author

9Erza

## Short description

Advanced telemetry dashboard for Forza Horizon Data Out on Stream Dock devices.

## Long description

ApexDash is an unofficial telemetry dashboard plugin for Stream Dock devices. It displays live Forza Horizon Data Out telemetry on Stream Dock buttons, including speed, RPM, gear, boost, power, fuel, tire data, grip status, input monitoring, session stats and telemetry connection status.

This is a data-only plugin. It does not include hotkeys, game automation, SimHub relay, memory reading, injection, or game modification.

## Requirements

- Windows 10/11
- Stream Dock software 2.10.179.426 or newer
- Forza Horizon Data Out enabled
- Data Out IP: 127.0.0.1
- Data Out Port: 23666
